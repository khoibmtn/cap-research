## Important Context for Next Session
1. **SPSS field mapping**: `patientToSpssRow.ts` maps patient fields using assumed property names. If any field doesn't exist on the Patient type, it will silently map to null (SYSMIS). Test with real data.
2. **SAV binary format**: Uncompressed Level-2. SPSS 16+ can read it. Value labels work correctly for shared templateKey groups.
3. **Slot templates**: Variables with `isSlotTemplate=true` and `{n}` / `{k}` in name are expanded at export time. The Settings UI shows them with [template] badge.
4. **Firestore path**: SPSS config stored at `app_settings/spss_config`. First load: falls back to buildDefaultSpssConfig() if not found.
